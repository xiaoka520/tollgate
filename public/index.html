Turn any API into an
agent-payable API.

Tollgate is a metered reverse proxy. Point it at an HTTP API you already run and every call becomes payable on Solana: the gateway answers 402 Payment Required with a quoted invoice, the caller settles it on chain, Tollgate verifies the transfer and proxies the request through. No accounts, no API keys, no subscriptions — payment is authentication.

The self-test uses a faucet-funded devnet wallet and a real on-chain transfer — nothing is simulated.

How it works

GET /g/:id/your-endpoint→ 402 + invoice→ agent pays on Solana→ retry with reference→ 200 + payload
01

Unique reference per call

Every unpaid request mints a fresh Solana address used as a Solana Pay style reference, so settlements are matched without the caller ever registering.

02

Verification, not trust

Tollgate reads the signatures that touched the reference and checks the recipient's lamport balance actually grew by the quoted price.

03

On-chain memo receipts

Each settled call leaves a tollgate:<gateway> memo, so metering is self-describing and auditable from any explorer.

04

Zero code changes upstream

Your existing service keeps speaking plain HTTP. Tollgate handles the paywall, metering and receipt headers.

Sandbox upstream

    
A real API shipped with Tollgate, serving live Solana devnet metrics. Free at /sandbox/*; metered once you put a gateway in front of it.

    

      
GET /sandbox/network-report
Slot, block height, epoch progress and rolling TPS straight from the cluster.

      
GET /sandbox/priority-fees
Median and peak prioritization fees from recent blocks.

      
POST /sandbox/echo
Echoes the JSON body back — handy for testing metered write endpoints.

    

    
curl -s http://127.0.0.1:8099/g/<gatewayId>/network-report
# → 402 with an invoice
npx tsx scripts/agent-pay.ts "http://127.0.0.1:8099/g/<gatewayId>/network-report"
# → settles on devnet, retries, prints the paid payload
